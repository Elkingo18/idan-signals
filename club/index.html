📘 כניסה עם פייסבוק — הגדרה חד-פעמית

הכפתור כבר קיים במסך הכניסה. כדי שהוא יעבוד, יש שלב שרק אתה יכול לעשות (אתה מקליד, לא אני):
1. developers.facebook.com ‹ My Apps ‹ Create App ‹ סוג "Authenticate and request data from users with Facebook Login" ‹ תן שם (Idan's Money Club).
2. בתוך האפליקציה: Use cases ‹ Authentication ‹ Settings ‹ העתק את App ID ואת App Secret.
3. console.firebase.google.com ‹ idan-money-club ‹ Authentication ‹ Sign-in method ‹ Facebook ‹ Enable ‹ הדבק את השניים ‹ העתק משם את כתובת ה-OAuth redirect ‹ הדבק אותה בפייסבוק תחת Facebook Login ‹ Settings ‹ Valid OAuth Redirect URIs.
4. בפייסבוק: App Review ‹ עד שהאפליקציה במצב Live, רק אתה ומי שתוסיף כ-Tester יכולים להתחבר — הוסף את רובי והחברים תחת Roles ‹ Testers לבינתיים.
